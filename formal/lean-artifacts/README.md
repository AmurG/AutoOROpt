# Lean Artifacts

This folder collects non-toy Lean artifacts that are concrete enough to upload with the paper.

At the moment it contains one fully wired case:

- `openroad_timing_weight_clamp/`: a real OpenROAD patch, a manifest that binds that patch to a Lean contract, the completed proof, and the before/after Aristotle repair files.

This repo only has one manifest-backed real case in `formal/`; the smaller toy examples remain there and are not duplicated here.

Start with `openroad_timing_weight_clamp/README.md`.
